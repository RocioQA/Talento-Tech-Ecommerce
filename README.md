# Talento Tech Ecommerce
Sitio web de una tienda de tecnología desarrollado como práctica del curso **Front-End de Talento Tech** Comisión #26238.

## Propósito
Presentar la tienda y ofrecer un formulario de contacto funcional para que los clientes puedan enviar consultas.

## Formulario de contacto
El formulario está configurado con el endpoint de Formspree en `pages/contacto.html`:

```html
<form action="https://formspree.io/f/xnpjdggl" method="POST">
```
